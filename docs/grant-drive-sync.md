# «Грант»: голубая шахматка из файла отельера

Дата: 24.08.2026.

## Зачем так сложно

Отельер ведёт сетку в OneDrive. Ссылка открывается только под личной учётной
записью Microsoft — наш сервер по ней получает страницу входа, а не файл.
Поэтому между OneDrive и нами стоит папка Google Drive:

```
OneDrive отельера  →  [скачать .xlsx]  →  папка Google Drive  →  наш сервер
```

Папка: **«Грант — шахматка»**
`https://drive.google.com/drive/folders/1Z8Du1NPCa6t9OEcJ43aPe2VzA-SfM-AV`

Владелец папки — наш сервис-аккаунт `sheet-bot@sonorous-bounty-488706-q9.iam.gserviceaccount.com`,
у Дарьи права редактора. Так сделано намеренно: **у сервис-аккаунта нулевая
квота хранения**, своих файлов он держать не может, а файл, загруженный Дарьей,
принадлежит ей и занимает её место. Читает бот по ключу `GOOGLE_SA_B64` —
тому же, что уже используется для Google-таблиц.

**Обновить занятость = положить в папку свежую выгрузку .xlsx.** Берётся самый
свежий файл; старые можно не удалять.

## Как читается книга

Разбор — `src/app/api/mirror/_lib/grantXlsx.ts`, проверено на боевом файле
«ГО сетка 2026».

- строка 2 — месяц (объединён на весь месяц), строка 3 — число;
  сетка идёт с мая 2026 по апрель 2027, год переводится на убыли номера месяца;
- столбец A — раздел, столбец B — название номера (совпадает с нашим;
  сравниваем без пробелов и регистра);
- **бронь = объединённая ячейка с текстом**; объединение по вертикали означает
  бронь сразу на несколько номеров (компания заняла два коттеджа);
- **объединение покрывает НОЧИ, день выезда остаётся вне его** — тот самый
  фиолетовый квадрат. Выезд = последняя ночь + 1, цвет читать не нужно;
- раздел **«Эконом» пропускается целиком** — отель нам его не продаёт;
- прошедшие ночи не переносим.

Одна книга обслуживает три наших объекта: «Грант отель» (12 номеров),
«Грант коттеджи» (14), «Грант апартаменты» (6). Каждый берёт свои номера по
названию, тег меток общий — `xlsx_grant`.

### Найденная дыра

Первый, ручной перенос **пропустил брони, объединённые по вертикали**. Номер
**«3ч №7» стоял свободным, хотя занят** 24.08–02.09 и 08.09–17.09 (группы на
5 и 6 человек занимают сразу №6 и №7). Новый разбор это чинит — риск двойной
продажи закрывается при первой же синхронизации.

## Что осталось

1. **Положить файл в папку** — без него кнопка честно скажет, что файла нет.
2. Выкатить ветку `codex/grant-drive-xlsx`.
3. Крон по расписанию: сейчас занятость обновляет кнопка «Обновить» и
   автоподтяжка при подборе (если данные старше 10 минут). Отдельный
   почасовой воркфлоу не делали — файл всё равно меняется только тогда,
   когда в папку кладут новую выгрузку.
4. Полная автоматика (без ручного перекладывания файла) требует, чтобы
   **отельер дал ссылку «для всех, у кого есть ссылка»** — тогда сервер
   заберёт файл прямо из OneDrive. Это письмо отельеру, отдельная задача.
