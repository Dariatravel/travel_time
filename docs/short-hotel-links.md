# Короткие ссылки объектов Абхазберег

## Как устроен сайт

`абхазберег.рф` — статический HTML-сайт из репозитория
`Dariatravel/lending_pervyi`. Он публикуется в Yandex Object Storage и
раздаётся через Yandex Cloud CDN. У статического хостинга нет таблицы
серверных псевдонимов для каждой карточки, поэтому короткий адрес реализован
отдельным маленьким `index.html`.

Страница короткого адреса:

- отвечает HTTP 200;
- мгновенно переводит браузер на существующую длинную карточку;
- содержит `rel="canonical"` на длинный адрес и `noindex`, поэтому не создаёт
  дубль страницы для поисковиков;
- не требует переименования или удаления длинного адреса. Старые ссылки из
  Telegram и Авито продолжают работать.

## Безопасный запуск

В GitHub Actions откройте **Short Hotel Links**.

Обычный запуск и еженедельный запуск по расписанию делают только отчёт.
Расхождения перечисляются в отчёте и не мешают обработать независимо
проверенные объекты. Для диагностического запуска, который должен завершаться
ошибкой при любом расхождении, у скрипта есть аргумент `--strict`.

1. `apply_site = true` — создать и опубликовать недостающие страницы.
2. Дождаться публикации сайта и проверить отчёт.
3. Для записи проверенных ссылок установить `update_database = true` и ввести
   контрольную фразу `UPDATE_SHORT_LINKS`.

Перед каждым обновлением `hotels.telegram_url` скрипт проверяет HTTP 200 и
убеждается, что короткая страница ведёт именно на ожидаемую длинную карточку.
Существующие короткие ссылки не перезаписываются.

Для публикации в репозиторий сайта нужен GitHub Actions secret
`SHORT_LINKS_SITE_TOKEN` с правом записи в `Dariatravel/lending_pervyi`.

Отчёты запуска сохраняются в artifact `short-hotel-links-report`:

- `short-hotel-links-report.txt` — читаемый журнал «было / стало»;
- `short-hotel-links-report.json` — структурированный журнал для автоматики.

## Точечное исправление

Workflow **Set Hotel Link** меняет ссылку одного объекта. По умолчанию это
сухой прогон. Для записи нужны `apply = true` и контрольная фраза
`UPDATE_HOTEL_LINK`. URL обязательно должен ответить HTTP 200.

## Что не затрагивается

Скрипты работают только с `hotels.telegram_url` и HTML-страницами-псевдонимами.
Поиск, шахматки, занятость и записи `manual_belvedere` не читаются и не
изменяются.
